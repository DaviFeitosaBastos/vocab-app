# Roadmap — App de Vocabulário
## Fase 0 — Preparar os dados

- Baixar merged.json (nightblade9/simple-english-dictionary) — sem filtro, com xingamentos/+18 incluídos
- Opcional: baixar lista de frequência (wordfreq-en-25000) pra ordenar por relevância
- Escrever um script simples que converte esses arquivos no formato final: lista com id, word, definition, synonyms, antonyms (e nsfw: true/false se decidir separar depois)
- Resultado dessa fase: um dictionary.json pronto, sentado no seu disco

## Fase 1 — Lógica em Python puro (sem GUI, sem POO)

- Função pra carregar dictionary.json
- Função pra carregar progress.json (lista de ids vistos; cria vazio se não existir)
- Função pra sortear N palavras do dicionário que ainda não estão em progress.json
- Função pra marcar palavras como vistas e salvar progress.json de volta no disco
- Função de busca: dado um termo, acha no dicionário completo e diz se já foi visto
- Testar tudo isso via print() no terminal, sem interface nenhuma
- Resultado dessa fase: você roda python main.py e vê no terminal as palavras do dia, consegue marcar como visto, e ao rodar de novo elas não repetem

## Fase 2 — Interface no navegador (HTML/CSS/JS), ainda sem Python

- Monta a tela do dia (lista de palavras + botão "marcar como aprendida")
- Monta a tela de busca
- Monta a tela de progresso (quantas vistas, lista do que já foi visto)
- Usa dados fake/fixos no JS por enquanto, só pra validar o visual e a navegação entre telas
- Resultado dessa fase: interface bonita rodando no navegador, mas ainda sem dados reais

## Fase 3 — Integrar Python com a interface via PyWebView

- Instalar pywebview + dependências do sistema (já resolvido no Fedora)
- Criar uma classe simples que "embrulha" as funções da Fase 1 pra expor pro JS
- Trocar os dados fake da Fase 2 pelas chamadas reais (pywebview.api.algumaFuncao())
- Testar o fluxo completo: abre o app, vê palavras do dia, marca como visto, fecha, abre de novo e o progresso continua salvo

## Fase 4 — Polimento

- Ajustar onde o progress.json fica salvo (pasta de configuração do usuário, não na pasta do projeto)
- Melhorar a tela de busca e progresso com filtros
- Decidir se quer separar conteúdo NSFW com toggle nas configurações

## Fase 5 — Empacotar como AppImage

- Gerar executável standalone com PyInstaller
- Empacotar com appimagetool ou python-appimage
- Testar em outra máquina/pasta limpa pra garantir que não depende de nada externo

## O que você vai precisar como entrada:

merged.json — o dicionário grande e desorganizado (que você já tem)
Uma lista de frequência de palavras em inglês (ainda precisamos baixar — o wordfreq-en-25000 que apareceu na busca, formato [["the", -2.1], ["house", -5.3], ...])

### Algoritmo do script, passo a passo:

- Carrega o merged.json inteiro na memória
- Carrega a lista de frequência inteira na memória
- Cria uma lista vazia chamada dicionario_final
- Cria um contador id_atual = 1
- Pra cada palavra da lista de frequência, na ordem que ela aparece (já vem ordenada por importância):

- Converte a palavra pra MAIÚSCULO (porque é assim que tá no merged.json)
- Procura essa palavra dentro do merged.json
- Se não encontrar → pula pra próxima palavra da lista de frequência
- Se encontrar, mas MEANINGS estiver vazio → pula pra próxima também
- Se encontrar e tiver pelo menos um significado:

Pega o primeiro item de MEANINGS (classe gramatical + definição)
Monta uma entrada nova: {"id": id_atual, "word": palavra_minuscula, "part_of_speech": classe, "definition": definicao, "synonyms": lista_de_sinonimos}
Adiciona essa entrada na dicionario_final
Incrementa id_atual em 1
